# Pasta de Áudio

Esta pasta é para armazenar os arquivos de áudio do aplicativo.

## Arquivos necessários:

### Áudio Principal:
- `interpretacao-cartas.mp3` (ou `.m4a`) - Áudio de 30 minutos com a interpretação das 3 cartas

### Frequências Sonoras (opcional - são geradas automaticamente):
- `frequencia-432hz.mp3` - 9 minutos
- `frequencia-528hz.mp3` - 12 minutos  
- `frequencia-741hz.mp3` - 10 minutos
- `frequencia-852hz.mp3` - 12 minutos
- `frequencia-delta.mp3` - 8 minutos

## Nota:

O aplicativo funciona **sem arquivos de áudio** - ele gera as frequências automaticamente usando Web Audio API.

Se você adicionar arquivos de áudio reais nesta pasta, o aplicativo os usará automaticamente em vez de gerar as frequências sintéticas.
